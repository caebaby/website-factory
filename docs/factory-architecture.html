Website Factory — System Architecture

Unified Hermes workflow for Chris & Johnny — multi-model routing, HITL gates, GitHub collaboration

Why Not LangChain?

  • • factory.js already IS the orchestrator
  • • Subprocess spawning = zero framework lock-in
  • • File-based state = GitHub-native collaboration
  • • Any CLI, any model, any provider — swap freely
  • • No abstraction tax, no API churn

HITL Is The Product

  • • Direction gate: wrong direction = one section, not a site
  • • Ship gate: every correction compounds (LEDGER)
  • • PR review = Johnny's gate, not a Slack ping
  • • Full automation is a pipe dream; checkpoints compound
  • • State persists between runs — resume anywhere

Scheduling Strategy

  • • Cron (no_agent): cost/billing watchdogs — $0
  • • Manual: client builds — HITL gates required
  • • Agent cron: ICP monitoring, content drafts
  • • Never cron a build: gates exist for a reason
  • • The right answer depends on whether reasoning is needed

Cost & Quality Evaluation

  • • cost_tracker.py: real tokens from Hermes state.db
  • • pricing.json: user-maintained rate table
  • • Gauntlet: deterministic quality gate (0 P0 to ship)
  • • Bench packet: model audition (one-shot build test)
  • • Build Registry: every run logged with metrics
